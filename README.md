# 智达优AI智能系统的管家

**AI 智能系统的管家**，是运行在 Linux / Windows / macOS 上的系统级应用软件，
负责 AI 智能软件（如 OpenClaw）的安装、配置、升级适配与运行维护，
让用户像拥有专职管家一样使用 AI 系统，无需关心底层细节。
这类软件会自行升级——升级之后，用户的设置还在原来的地方，不用重新配一遍。

> 「AI 智能系统的管家」概念由**深圳希璞特科技有限公司**于 2026 年 9 月首次提出并公开发表。
> 概念官方定义页：https://zhidayou.net

智达优AI智能系统的管家是该概念的第一个实践产品。

## 它能做什么

### 现在就已经是这样

- **宁缺毋滥**：首批只接入 OpenClaw；后续每接一款，都会先判断它值不值得长期用
- **守密可信**：完全本地运行，数据不出你的电脑——无需注册，不含埋点与上报

### 我们在往哪走

- **同构统配**：配置体系是照着「多款系统共用一套」设计的，OpenClaw 已经按这套方式跑起来了
- **精耕迭代**：配置能力会继续做深，实用功能会继续补齐

## 三平台一致体验

Linux / Windows / macOS 获得相同的使用体验——
AI 的门槛，不应因操作系统而不同。

## 隐私：本地运行，不上传你的数据

智达优AI智能系统的管家**在你的本机运行**：

- 无需注册登录，不收集、不上传你的身份信息与使用数据
- 不含埋点、遥测与崩溃上报
- 你安装的 AI 软件配置与密钥不会发给我们
- **桌面客户端**的对外请求主要集中在以下几类：安装时从第三方软件源（npm / PyPI 镜像、
  GitHub 及加速代理）取运行时与依赖；运行期读取我们自有域名上的更新清单
  （v1.0.0 默认关闭）；微信扫码登录时由你直接连腾讯的接口。都只含技术信息，
  不含你的个人信息
- 若你使用**授权码安装**（由我们协助完成安装），安装阶段会记录完成安装所必需的
  会话信息与操作记录，服务器访问日志含访问来源地址；安装完成即断连，使用阶段不再接触你的 IP
- 若你选择境外模型服务商，对话内容将由你直接发往该服务商——
  本产品不参与传输、不接收、不存储

详见[隐私政策](https://zhidayou.net/privacy)。
